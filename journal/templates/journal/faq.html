{% trans "С чего начать" %}

{% blocktrans %}Журнал живёт в браузере, устанавливать ничего не нужно. Откройте адрес журнала, который дал администратор, введите логин и пароль — и вы внутри.{% endblocktrans %}

{% blocktrans %}Везде работает одно правило: сначала выберите год, полугодие и адрес в шапке, потом работайте. То, что вы видите в списках, относится именно к выбранному полугодию и адресу.{% endblocktrans %}

{% trans "Три роли" %}

  • {% blocktrans %}Методист (УМО) — ведёт учеников, программы, группы, расписание, смотрит темы и посещаемость, делает выгрузки.{% endblocktrans %}
  • {% blocktrans %}Преподаватель — видит свои занятия, отмечает посещаемость и записывает темы занятий.{% endblocktrans %}
  • {% blocktrans %}Администратор — то же, что методист, плюс сотрудники, резервные копии, безопасность и демо-режим.{% endblocktrans %}

{% blocktrans %}Слева — меню. Ссылки в нём зависят от роли: преподаватель видит «Мои занятия» и «По неделям», методист — «Ученики», «Программы и группы», «Расписание» и так далее. Справа сверху, у своего имени, — компактное меню: «Мои данные и оформление» (ФИО, логин, смена пароля) и выход. Там же выбирается тема оформления: светлая, тёмная, ночная синяя, тёплая или контрастная. Темы лежат в блоке «Оформление» на странице «Мои данные». Тема применяется сразу и запоминается для браузера. На телефоне меню открывается кнопкой с тремя полосками в шапке: оно занимает всю высоту экрана и закрывается нажатием в любое свободное место или клавишей Escape. Ползунки прокрутки тоже оформлены в цветах темы. Сообщения журнала — например, «Сохранено» — появляются всплывающими уведомлениями справа сверху и через несколько секунд исчезают сами; закрыть можно крестиком. Если на устройстве включено уменьшение движения, переходы и анимации отключаются — так спокойнее и быстрее.{% endblocktrans %}

{% trans "Методисту" %}

{% blocktrans %}Порядок работы, к которому всё приспособлено: год, полугодие и адрес → программы и преподаватели → группы → ученики → расписание → темы и отметки → выгрузки.{% endblocktrans %}

{% trans "1. Полугодие и адрес" %}

{% blocktrans %}В шапке три «переключалки»: учебный год, полугодие и адрес. Год и полугодие выбираются отдельно: список полугодий зависит от выбранного года.{% endblocktrans %}

  • {% trans "В списке годов есть поиск: начните вводить год — список сузится, а Enter выберет первый подходящий вариант." %}
  • {% trans "Год и полугодия создаются автоматически: 1-е полугодие — 01.09–31.12, 2-е — 01.01–31.05." %}
  • {% trans "Адреса — «ул. Примерная, 1» и «ул. Вторая, 10». У каждого свой список кабинетов." %}
  • {% blocktrans %}Даты полугодий можно поправить в разделе «Учебные периоды»: учебные годы там идут плитками по 3–4 в ряд, а список годов выводится постранично.{% endblocktrans %}
  • {% trans "На телефоне панель компактная: переключатели переносятся на несколько строк, горизонтальной прокрутки нет." %}

{% blocktrans %}Если «пропала» программа или группа — почти всегда дело в том, что выбрано другое полугодие или другой адрес.{% endblocktrans %}

{% trans "2. Ученики и статус «отпускать при БП»" %}

{% blocktrans %}Раздел «Ученики»: добавить, изменить, удалить, найти по фамилии или имени.{% endblocktrans %}

{% trans "В таблицах журнала клик по заголовку столбца сортирует список, повторный клик включает обратный порядок. У служебных столбцов с кнопками сортировки нет." %}

  • {% blocktrans %}ФИО — обязательны фамилия и имя, отчество можно не заполнять.{% endblocktrans %}
  • {% blocktrans %}Дата рождения — можно не заполнять.{% endblocktrans %}
  • {% blocktrans %}Статус БП — «отпускать ребёнка во время беспилотной опасности»: Н — нет заявления, ЕН — есть заявление, не отпускать, ЕО — есть заявление, можно отпускать. Статус виден цветным значком в списке учеников и педагогу прямо в журнале отметок.{% endblocktrans %}
  • {% trans "В карточке ученика видно, в каких группах он состоит." %}

{% trans "Удаление ученика убирает и его отметки — если ребёнок просто ушёл из группы, лучше убрать его из состава группы, а не удалять карточку." %}

{% trans "3. Импорт детей из Excel" %}

{% blocktrans %}Раздел «Импорт учеников из Excel» (кнопка «Импорт из Excel» в списке учеников). Файл — .xlsx.{% endblocktrans %}

{% trans "Столбец" %}{% trans "Что писать" %}{% trans "Обязательно" %}
{% trans "1-й" %}{% trans "ФИО одной строкой: «Иванов Иван Иванович», «Иванов Иван», «Иванов И. И.»" %}{% trans "да" %}
{% trans "2-й" %}{% trans "Дата рождения: настоящая дата Excel или «01.09.2010»" %}{% trans "нет" %}
{% trans "3-й" %}{% trans "Статус: Н, ЕН или ЕО (можно словами)" %}{% trans "нет" %}
  • {% trans "Столбцы распознаются по содержимому, порядок и лишние столбцы не мешают; шапка, номера строк и пустые строки пропускаются." %}
  • {% trans "Если даты или статуса нет — ученик всё равно импортируется; в предупреждениях будет сказано, чего не хватило, а статус по умолчанию — «Нет заявления»." %}
  • {% trans "Перед сохранением показывается разобранный список: дата, статус, пометка «уже в базе»; галочки можно снять — такие строки не импортируются." %}
  • {% trans "Повторяющиеся не задваиваются: им дописываются только пустые поля." %}
  • {% trans "Можно сразу выбрать группу — все новые ученики попадут в неё." %}

{% trans "4. Программы и преподаватели" %}

{% blocktrans %}Раздел «Программы и группы». Программа создаётся внутри выбранного полугодия и адреса — это сделано специально, чтобы в каждом полугодии был свой набор программ.{% endblocktrans %}

{% blocktrans %}В карточке программы выбираются основной преподаватель и остальные ведущие — те, кто может вести и подменять. Ведущие отмечаются галочками: сверху есть поиск по фамилии, отмеченные поднимаются вверх списка. Основной преподаватель входит в состав автоматически и помечен подписью «основной». Если программу ведут два преподавателя, это не подмена: подмена отмечается галочкой у конкретного занятия.{% endblocktrans %}

  • {% blocktrans %}Основной преподаватель — тот, кто ведёт программу обычно. Он подставляется в занятие по умолчанию. Поиск в его списке появляется сам, если преподавателей больше семи.{% endblocktrans %}
  • {% blocktrans %}Остальные ведущие — те, кто может вести и подменять.{% endblocktrans %}
  • {% blocktrans %}Если преподавателя отключили, а он уже назначен программе, занятию или курсу, он остаётся в списке с пометкой «отключён» — старую запись можно сохранить без замены педагога.{% endblocktrans %}
  • {% trans "Если одна и та же программа нужна на двух адресах — создайте её на каждом адресе." %}

{% blocktrans %}Учётные записи преподавателей — в разделе «Преподаватели»: ФИО, логин, число программ, дата регистрации. В колонке «Активен» видно, работает учётная запись или отключена. Пароль журнал показывает один раз при создании преподавателя — скопируйте его сразу. Учётные записи методистов и администраторов создаются в админке Django.{% endblocktrans %}

{% trans "5. Группы и состав" %}

{% trans "Группа — это «поток», который ходит на занятия. Группы живут внутри программы." %}

  • {% trans "Создать группу: карточка программы → «Добавить группу»." %}
  • {% blocktrans %}Состав: кнопка «Состав группы» — отметить галочками нужных детей и сохранить. Ученики выводятся страницами («по 10 / 25 / 50 / 100»), а поиск ищет по всей базе, не только по открытой странице; дети группы, которых нет на текущей странице, сохраняются сами.{% endblocktrans %}
  • {% trans "Ученик может быть в нескольких группах (например, математика и физика)." %}
  • {% trans "Переименовать или удалить группу можно из карточки программы. Удаление группы убирает её занятия и отметки." %}

{% trans "6. Расписание" %}

{% blocktrans %}Раздел «Расписание»: кнопка «Добавить занятие». У занятия есть группа, день недели, начало и окончание, кабинет и преподаватель, а для разового занятия — ещё и дата. Расписание показано сеткой на неделю или списком по дням.{% endblocktrans %}

  • {% trans "Номеров уроков нет: всё определяет время. Окончание подставляется автоматически (+90 минут), можно изменить." %}
  • {% blocktrans %}Разовое занятие: заполните «Дата разового занятия», если занятие проходит один раз — например, мероприятие. День недели подставится по дате сам, а занятие появится в расписании, в неделях и в календаре группы только в этот день. Если дата пуста, занятие идёт каждую неделю по выбранному дню. Разовые занятия помечаются подписью «разовое · 12.10.2026»; при переносе в другое полугодие они не копируются (они привязаны к дате). По разовому занятию можно отметить посещаемость и выгрузить её: страница отметок открывается на его дату, а переходы «неделю назад и вперёд» для него не показываются.{% endblocktrans %}
  • {% trans "Кабинеты показываются только того адреса, к которому относится группа." %}
  • {% trans "Журнал проверяет три вещи: кабинет не занят, группа не занята, у преподавателя нет другого занятия в это время (на любом адресе)." %}
  • {% blocktrans %}Справа на странице занятия видно свободное время преподавателя: зелёные промежутки свободны, по клику время подставляется в форму. Панель пересчитывается на того преподавателя, которого вы выбрали. Смена преподавателя или дня недели обновляет панели сразу, без перезагрузки страницы; смена группы обновляет страницу, потому что от неё зависит список кабинетов.{% endblocktrans %}
  • {% blocktrans %}Подмена — отметка, что занятие ведёт заменяющий преподаватель: такое занятие помечается словом «подмена». Занятость заменяющего проверяется как обычно, поэтому галочка «Подмена» сама по себе занятое время не разрешает: если занятие нужно провести в уже занятое у заменяющего время, отметьте отдельно «1. Не учитывать занятость преподавателя». Если программу ведут два преподавателя — это не подмена: оба просто ведут программу.{% endblocktrans %}
  • {% trans "Картинку расписания можно скачать (PNG, вертикально или горизонтально) — в разделе «Выгрузка в Excel»." %}
  • {% trans "Расписание показывает одну неделю: по умолчанию текущую, листать можно кнопками «Предыдущая неделя / Текущая неделя / Следующая неделя» — внутри полугодия, на границах кнопки неактивны. Разовые занятия и подмены видны только в свою неделю, а пометка «отсутствует: …» — по показанной неделе. Выбранные неделя и вид (сетка или список) сохраняются." %}

{% trans "7. Темы занятий и академические часы" %}

{% blocktrans %}Темы заполняют преподаватели — в разделе «По неделям: темы и часы». На странице самого занятия тема только показывается. Часы считаются сами: 1 академический час = 45 минут (занятие 10:00–11:30 = 2 акад. часа).{% endblocktrans %}

  • {% blocktrans %}Посмотреть: раздел «Темы занятий» — сразу все темы с фильтрами по группе, преподавателю и датам, с итогом по академическим часам.{% endblocktrans %}
  • {% blocktrans %}Там же кнопка «Выгрузить в Excel» — выгрузка учитывает выбранные фильтры.{% endblocktrans %}
  • {% trans "Заполнить или поправить тему может и методист — в разделе «Посещаемость»." %}
  • {% trans "Если тема не сохранена, занятие в неделях помечается как «не отмечено» — это видно и методисту, и преподавателю." %}

{% trans "8. Недели и посещаемость" %}

{% blocktrans %}Раздел «Посещаемость» — рабочая лошадка методиста.{% endblocktrans %}

  • {% trans "Показывает выбранную неделю: занятия по дням, темы, часы, кто был и кого не было." %}
  • {% trans "Фильтры: группа, программа, преподаватель и неделя (кнопки «Предыдущая неделя», «Текущая неделя», «Следующая неделя»)." %}
  • {% blocktrans %}Отметки: Присутствовал, Отсутствовал, Опоздал — итоги видно по каждому занятию. Рядом есть поле темы и кнопка «Отметить», которая открывает журнал отметок этого дня.{% endblocktrans %}
  • {% trans "Рядом с каждым учеником виден статус БП (ЕО / ЕН / Н)." %}
  • {% trans "Листать недели можно только внутри полугодия: на первой неделе кнопка «Предыдущая неделя», на последней — «Следующая неделя» серые, без ссылки. Неделя из старой ссылки приводится к ближайшей допустимой — с подсказкой «Эта неделя вне полугодия». То же на странице преподавателя «По неделям: темы и часы»." %}
  • {% trans "Выгрузка недели в Excel — кнопкой на той же странице." %}

  • {% trans "Фильтры: поиск по мероприятию, ученику и направлению, статус, период дат." %}
  • {% trans "Выгрузка в Excel: лист с записями и лист «Сводка» (сколько победителей, призёров, участников)." %}
  • {% trans "Преподаватель видит свои записи и успехи своих учеников у себя в «Моих занятиях»." %}

{% trans "10. Повышение квалификации педагогов" %}

{% blocktrans %}Раздел «Повышение квалификации» (страница «Повышение квалификации педагогов»): дата, вид (повышение квалификации, конкурс, другое), педагог, название программы, образовательная организация, часы, результат.{% endblocktrans %}

  • {% trans "Фильтры по виду и педагогу, поиск по программе, организации и педагогу." %}
  • {% trans "Выгрузка в Excel со строкой «Итого часов»." %}
  • {% trans "Преподаватель видит только свои записи, правит и удаляет их сам. Поле выбора педагога у него отсутствует — запись оформляется на него автоматически. Методист ведёт записи всех педагогов." %}

{% trans "11. Перенос данных в другое полугодие или адрес" %}

{% blocktrans %}Раздел «Учебные периоды» → кнопка «Перенести из другого полугодия». Она есть и в списке программ, и в расписании, и в карточке программы. Выбираете, откуда и куда переносить.{% endblocktrans %}

  • {% trans "Переносятся программы, группы, занятия; по желанию — состав групп." %}
  • {% trans "Преподаватели программы и пометка подмены сохраняются." %}
  • {% trans "Занятия, которые не встают из-за конфликта по времени, пропускаются — в отчёте будет сказано, сколько." %}
  • {% trans "Повторный перенос не задваивает: существующие группы переиспользуются." %}

{% trans "12. Выгрузки" %}

{% blocktrans %}Раздел «Выгрузка в Excel». Все выгрузки — файлы .xlsx, открываются в Excel, «Мой офис», LibreOffice:{% endblocktrans %}

  • {% trans "ученики (с датой рождения, статусом БП и группами);" %}
  • {% trans "программы и группы выбранного полугодия и адреса;" %}
  • {% trans "расписание — и Excel, и картинкой PNG (вертикально/горизонтально);" %}
  • {% trans "посещаемость (с темой, часами и колонкой БП);" %}
  • {% trans "темы занятий с итогом по академическим часам;" %}

{% trans "13. Отсутствия преподавателей и подмены" %}

{% blocktrans %}Если преподаватель заболел или уехал в командировку, отметьте период в разделе «Отсутствия» — это подраздел «Преподавателей» в меню слева.{% endblocktrans %}

  • {% blocktrans %}«С» и «По» — границы периода: обе даты входят в него.{% endblocktrans %}
  • {% blocktrans %}«Причина» — «Больничный», «Командировка» или «Другое»; примечание можно не заполнять.{% endblocktrans %}
  • {% trans "Нажмите «Добавить отсутствие», выберите преподавателя и период и сохраните — запись появится в списке раздела, а убрать её можно кнопкой «Удалить»." %}
  • {% trans "Быстрее всего — из списка «Преподаватели»: кнопка «Отсутствие» открывает форму с уже выбранным преподавателем. В карточке преподавателя осталась строка «Отсутствует: …» со ссылкой «Отсутствия» и кнопкой «Поставить подмену»." %}
  • {% trans "Отмечают отсутствия методист и администратор: преподаватель период себе поставить не может." %}
  • {% trans "Периоды одного преподавателя не должны пересекаться, а дата «По» не может быть раньше даты «С» — такую запись журнал не сохранит." %}

{% blocktrans %}Занятия, попавшие в период отсутствия, считаются отменёнными.{% endblocktrans %}

  • {% blocktrans %}В «Посещаемости по неделям» и в «По неделям: темы и часы» у занятия стоит пометка «занятие отменено», а его часы вынесены в отдельную строку «отменено: N ч» — в общий итог они не входят.{% endblocktrans %}
  • {% blocktrans %}На странице отметок сверху видна красная плашка «Отсутствие: …», переключатели отметок и кнопка сохранения выключены: за эти дни посещаемость не ставится.{% endblocktrans %}
  • {% blocktrans %}В расписании рядом с преподавателем появляется «отсутствует: Больничный 13.01.2025–17.01.2025», а в выгрузке расписания (Excel) — колонка «Отсутствие преподавателя» с периодом.{% endblocktrans %}
  • {% trans "Уже поставленные отметки не удаляются — они просто не учитываются. Если период удалить, занятия снова станут обычными, а часы вернутся в итог." %}

{% blocktrans %}Как поставить подмену. Из карточки отсутствующего преподавателя кнопка «Поставить подмену» открывает недельный журнал на неделю отсутствия, а рядом с отменённым занятием в «Посещаемости по неделям» — форму нового занятия: группа, кабинет, день, дата и время уже заполнены, галочка «Подмена» уже отмечена — останется выбрать заменяющего. Вручную то же занятие создаётся в разделе «Расписание» кнопкой «Добавить занятие»: заполните группу, время и кабинет, в поле «Дата разового занятия» укажите дату из периода отсутствия, а в поле «Преподаватель занятия» выберите заменяющего.{% endblocktrans %}

{% blocktrans %}Занятость отсутствующего преподавателя подмене не мешает: в этот день он занятий не ведёт, поэтому подмену можно поставить даже на его обычное время. Занятость заменяющего, кабинет и группа проверяются как всегда. Если заменяющий в это время уже занят и подмена осознанная, отметьте галочку «1. Не учитывать занятость преподавателя»: галочка «2. Подмена (заменяющий преподаватель)» только помечает занятие значком «подмена» и проверку по времени не снимает.{% endblocktrans %}

{% blocktrans %}Подмены сразу на весь период. В строке периода есть кнопка «Подмены»: страница показывает все занятия преподавателя в периоде по датам — и обычные, и разовые. Сверху можно выбрать «Один заменяющий на все дни» — он подставится во все строки; лишние строки снимаются галочкой «Ставить». Конфликты видно сразу: строка подсвечена и написано, что мешает («Занят: …», «Кабинет … занят», «У группы уже есть занятие», «Заменяющий отсутствует в этот день»). Занятость заменяющего снимается галочкой «Не учитывать занятость» у этой строки, занятость кабинета и группы — нет. Повторный запуск дублей не создаёт: журнал пишет «Уже стояли подмены», а после сохранения — «Создано подмен: N, пропущено: M.» и возвращает в «Отсутствия».{% endblocktrans %}

{% blocktrans %}Раздел «Подмены». Под «Отсутствиями» в меню есть подраздел «Подмены» — список уже поставленных подмен. Там видно дату, время, группу, кабинет, кто ведёт и кого заменяет (с периодом отсутствия), есть фильтры по заменяющему, заменяемому, датам и группе, а в строке — кнопки «Отметки» и «Изменить». Создавать подмены здесь нельзя: только смотреть и находить.{% endblocktrans %}

{% blocktrans %}Отметки на подмене. Подмена — обычное занятие на конкретную дату, поэтому отметки на ней доступны: их ставит сотрудник УМО и сам заменяющий, тема тоже сохраняется. Часы подмены идут заменяющему, а у отсутствующего занятие по-прежнему исключено («отменено: N ч»). Заменяющий на своих страницах видит подпись «Подмена для Иванов И. И. · Больничный с 05.10.2026 по 11.10.2026»; у отсутствующего этого занятия нет. Поставить подмену тому, кто сам отсутствует в этот день, журнал не даст — форма напишет «‹ФИО› отсутствует ‹дата›: …».{% endblocktrans %}

{% blocktrans %}Кого заменяют. Журнал хранит это у самого занятия: поле «3. Кого заменяют (для подмены)» в форме занятия (можно не заполнять) и подпись «Подмена для …» в журналах берутся оттуда — даже если исходное занятие потом перенесли. У старых подмен поле пустое, и подпись по-прежнему ищется по совпадению группы, даты и времени.{% endblocktrans %}

{% blocktrans %}Кто может вести занятие. Только преподаватель программы — основной или дополнительный из карточки программы (раздел «Программы», блок «Преподаватели программы»). Чужого преподавателя ни форма занятия, ни список заменяющих в строке не примут: «‹ФИО› не ведёт программу «‹название›»». Уже стоящие занятия с прежним преподавателем при этом правятся и сохраняются как есть, пока преподавателя не меняют.{% endblocktrans %}
