# Скриншоты для README

Сюда кладутся снимки интерфейса. Файлы с такими именами README подхватит сам:

| Файл | Что снимать |
| --- | --- |
| `dashboard.png` | Главная — сводка со статистикой и графиком входов |
| `schedule.png` | Расписание: сетка по дням, кнопки листания недель и подпись недели |
| `weeks.png` | Посещаемость: недельная таблица с отметками |
| `absences.png` | Отсутствия: список периодов и кнопка «Подмены» |
| `substitutions.png` | Подмены на весь период (по желанию) |
| `customization.png` | Оформление с загрузкой логотипа и окном обрезки (по желанию) |

Требования простые: демонстрационные данные (реальные имена и адреса не нужны),
ширина окна от 1280 пикселей, тёмная тема не обязательна. Формат PNG.

Снимать проще всего в демонстрационном режиме: включите `DEMO_MODE=1`, откройте
журнал и войдите как демо-пользователь — данные там вымышленные.
